# Эмулятор оболочки ОС (Вариант 24)

## Общее описание
Проект представляет собой эмулятор командной строки UNIX-подобной ОС. 
Поддерживает работу с виртуальной файловой системой (VFS) в формате JSON, 
раскрытие переменных окружения и выполнение команд через скрипты.

## Описание функций и настроек
- **REPL**: Интерактивный режим с приглашением, содержащим имя VFS.
- **Переменные окружения**: Поддержка синтаксиса `$VAR` и `${VAR}`.
- **Конфигурация**: Параметры `--vfs` (путь к JSON) и `--script` (путь к скрипту).
- **VFS**: Загружается в память из JSON. Поддерживает текст и base64.
